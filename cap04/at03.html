2. Ranking de Tecnologias

  1. JavaScript

    A linguagem essencial para interatividade no navegador.

  2. Python

    Muito utilizada para Backend e Ciência de Dados.

  3. SQL

    Fundamental para manipulação de bancos de dados relacionais.

  4. TypeScript

    Uma camada de segurança de tipos sobre o JavaScript.

  5. React

    Biblioteca líder para construção de interfaces modernas.

3. Glossário Técnico

HTML
Linguagem de marcação para web.
Sigla para HyperText Markup Language.
CSS
Folhas de estilo em cascata.
Tecnologia usada para definir a aparência visual de páginas.
Client-side
Frontend
Tudo aquilo que é executado no navegador do usuário final.
Server-side
Backend
Lógica e processamento que ocorrem no servidor.
DOM
Document Object Model, representação da página em árvore.
API
Interface de programação para comunicação entre sistemas.
